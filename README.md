# 📘 week_2 JavaScript Practice Portfolio

A beginner-friendly JavaScript practice project organized over two days of exercises. It includes array operations, module usage, task management, shallow vs deep copies, spread/rest operators, timer functions, and a small book example.

## 🚀 Project Overview

This repository contains practical JavaScript assignments built for learning core programming concepts. The work is divided into `day_3` and `day_4` folders, each focusing on a different set of exercises and hands-on code examples.

## 🧩 Assignment Details

| Day | Folder / File | Focus Area | Description |
|---|---|---|---|
| Day 3 | `Array-operations-simple/` | Basic array methods | Practice simple array operations with `simple_arr1.js`, `simple_arr2.js`, and `simple_arr3.js` |
| Day 3 | `Array-operations-advanced/` | Advanced array techniques | Explore more complex array logic in `adv_arr1.js` through `adv_arr5.js` |
| Day 3 | `module2/` | Modular JavaScript | Build reusable code with `app.js`, `cart.js`, `discount.js`, `payment.js`, and `product.js` |
| Day 3 | `task-management/` | Task app logic | Implement task creation and validation using `main.js`, `task.js`, and `validator.js` |
| Day 4 | `book.js` | Object handling | Work with book data and object usage in a standalone example file |
| Day 4 | `Shallow-deepcopy/` | Copy behavior | Compare `deepcopy.js` and `shallow copy.js` to understand shallow vs deep copies |
| Day 4 | `Spread-operator-rest-parameter/` | Modern syntax | Learn spread and rest syntax through `spreadoperator.js` |
| Day 4 | `timer-functions/` | Timing utilities | Explore timers with `examsimulator.js` and `otpcountdown.js` |

## ▶️ How to Run the Project

This project uses plain JavaScript files that run with Node.js.

1. Open a terminal in the `week_2` folder.
2. Run any example file with Node.js:

```bash
node day_3/module2/app.js
node day_4/book.js
node day_4/Spread-operator-rest-parameter/spreadoperator.js
```

3. For task and array examples, use the file path you want to execute:

```bash
node day_3/task-management/main.js
node day_3/Array-operations-simple/simple_arr1.js
node day_4/timer-functions/otpcountdown.js
```

> Tip: If you do not have Node.js installed, download it from [https://nodejs.org](https://nodejs.org).
